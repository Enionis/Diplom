# Матрица Судьбы - Документация

## Описание

Модуль "Матрица Судьбы" был успешно перенесен из веб-версии в мобильное приложение и интегрирован во вкладку "Эзотерика". Он позволяет пользователям рассчитать свою матрицу судьбы на основе даты рождения и получить подробную информацию о:

- Предназначении (личном, социальном, духовном, планетарном) по возрастам 20-40 и 40-60 лет
- Талантах и способностях
- Финансах и карьере (направление деятельности, ключи к успеху)
- Жизненных испытаниях
- Характере и суперсиле

## Расположение

Матрица судьбы находится во вкладке **"Эзотерика"** → **"Матрица судьбы"**

## Структура файлов

### Утилиты
- `utils/destinyMatrix.ts` - Основные функции расчета матрицы судьбы
  - `calculateDestinyMatrix()` - главная функция расчета
  - `reduceNumber()` - приведение числа к диапазону 1-22
  - `calculateYear()` - вычисление суммы цифр года

### Хуки
- `hooks/useDestinyMatrix.ts` - React хук для работы с матрицей судьбы (опционально)

### Компоненты
- `components/DestinyMatrixSVG.tsx` - SVG компонент для визуализации матрицы

### Константы
Все константы перенесены из веб-версии:
- `constants/purpose.ts` - Предназначение по возрастам (20-40, 40-60)
- `constants/talents.ts` - Описания талантов (1-22)
- `constants/challenges.ts` - Жизненные испытания
- `constants/health.ts` - Здоровье и чакры
- `constants/money.ts` - Финансы и карьера
- `constants/relationships.ts` - Отношения (для мужчин и женщин)
- `constants/children.ts` - Дети
- `constants/management.ts` - Управление
- `constants/parents.ts` - Родители
- `constants/pastLives.ts` - Прошлые жизни
- `constants/yearForecast.ts` - Прогноз по годам
- `constants/destinyMatrix.ts` - Главный файл экспорта всех констант

### Интеграция
- `app/(tabs)/horoscope.tsx` - Главная страница эзотерики с интегрированной матрицей судьбы

## Использование

### В приложении

1. Откройте вкладку "Эзотерика"
2. Введите дату рождения (если еще не введена)
3. Переключитесь на вкладку "Матрица судьбы"
4. Выберите интересующий раздел:
   - **Визуализация** - графическое отображение матрицы с предназначениями
   - **Предназначение** - подробное описание жизненного пути
   - **Таланты** - ваши врожденные способности
   - **Деньги** - направление деятельности и ключи к финансовому успеху
   - **Испытания** - жизненные вызовы и как их преодолеть

### Программно

```typescript
import { calculateDestinyMatrix } from '@/utils/destinyMatrix';

const birthDate = '1990-05-15'; // YYYY-MM-DD
const matrixData = calculateDestinyMatrix(birthDate);

console.log(matrixData.points); // Массив точек матрицы
console.log(matrixData.purposes); // Предназначения
console.log(matrixData.chartHeart); // Чакры сердца
```

### Использование компонента

```typescript
import DestinyMatrixSVG from '@/components/DestinyMatrixSVG';

<DestinyMatrixSVG 
  matrix={matrixData.points} 
  width={350} 
  height={300} 
/>
```

## Структура данных

### MatrixPoint
```typescript
interface MatrixPoint {
  value: number;      // Значение точки (1-22)
  locked?: boolean;   // Заблокирована ли точка
}
```

### MatrixData
```typescript
interface MatrixData {
  points: MatrixPoint[];  // 36 точек матрицы
  purposes: {
    skypoint: number;           // Небо
    earthpoint: number;         // Земля
    perspurpose: number;        // Личное предназначение
    femalepoint: number;        // Женская линия
    malepoint: number;          // Мужская линия
    socialpurpose: number;      // Социальное предназначение
    generalpurpose: number;     // Общее предназначение
    planetarypurpose: number;   // Планетарное предназначение
  };
  chartHeart: {
    // Физика, энергия и эмоции для 7 чакр
    // (sahphysics, ajphysics, vishphysics, anahphysics, manphysics, svadphysics, mulphysics)
    // (sahenergy, ajenergy, vishenergy, anahenergy, manenergy, svadenergy, mulenergy)
    // (sahemotions, ajemotions, vishemotions, anahemotions, manemotions, svademotions, mulemotions)
  };
}
```

```
0  - E (центр) - основное предназначение
1  - A (день рождения)
2  - B (месяц рождения)
3  - C (год рождения)
4  - D
5  - F
6  - G
7  - I
8  - H
9  - S
10 - T
11 - N
12 - J
13 - W
14 - X
15 - L (направление деятельности для денег)
16 - K
17 - O
18 - P
19 - Q
20 - R
25 - M (для достижения успеха в деньгах)
26-35 - Дополнительные точки (F1, F2, G1, G2, I1, I2, H1, H2, U, V)
```

## Вкладки матрицы

1. **Визуализация** - SVG отображение матрицы с основными предназначениями
2. **Предназначение** - детальное описание жизненного пути (меняется в зависимости от возраста: 20-40 или 40-60 лет)
3. **Таланты** - врожденные способности и дары
4. **Деньги** - направление деятельности и ключи к финансовому успеху
5. **Испытания** - жизненные вызовы и способы их преодоления

## Зависимости

- `react-native-svg` - Отображение SVG матрицы
- `@react-native-community/datetimepicker` - Выбор даты (уже установлен)

## Особенности реализации

1. Все расчеты выполняются на клиенте
2. Данные не сохраняются в базе данных (используется только дата рождения из профиля)
3. SVG компонент адаптивный и масштабируется
4. Поддержка iOS и Android
5. Все константы на русском языке
6. Интерфейс с вкладками для удобной навигации
7. Интеграция с существующей системой премиум-подписки
8. Автоматический расчет возраста для выбора правильного описания предназначения

## Отличия от веб-версии

1. Упрощенная визуализация (без сложных линий и декоративных элементов)
2. Интеграция в существующую вкладку "Эзотерика"
3. Мобильно-адаптивный интерфейс
4. Вкладки вместо длинного скролла
5. Сохранение стилистики приложения
