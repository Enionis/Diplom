Кросс-платформенное приложение «MYstic» - Мистическая платформа для самопознания

## КРАТКОЕ ОПИСАНИЕ ПРОЕКТА

**ДЛЯ КОГО** (целевой сегмент)
Для молодых людей 18-35 лет, преимущественно женщин, живущих в городах и интересующихся эзотерикой, астрологией и самопознанием.

**КОТОРЫЕ НЕДОВОЛЬНЫ** (текущая альтернатива)
Которые недовольны разрозненностью эзотерических сервисов, высокой стоимостью консультаций астрологов (от 2000 руб./сеанс), сложностью изучения астрологии и отсутствием качественных русскоязычных приложений с полным функционалом.

**НАШ ПРОДУКТ** (ваша продуктовая категория)
Наш продукт – это кросс-платформенное мобильное приложение и веб-сайт для мистических практик и самопознания с единой базой данных.

**КОТОРЫЙ ПОЗВОЛЯЕТ** (ключевое решение)
Который позволяет получать персонализированные гадания на Таро, рассчитывать матрицу судьбы, читать гороскопы и проходить психологические тесты в одном интерфейсе.

**В ОТЛИЧИЕ ОТ** (альтернативные решения)
В отличие от Co-Star и The Pattern (нет русского языка, ограниченный функционал) и "Матрица судьбы. Нумерология и Таро" (плохой интерфейс, много багов), мы предоставляем полноценную русскоязычную платформу с качественным дизайном и стабильной работой.

**МЫ СДЕЛАЛИ** (ключевой функционал)
У нас есть React Native мобильное приложение, веб-версия на том же стеке, Node.js API с MySQL базой данных, система аутентификации и подписок, а также интеграция с внешними API для актуальных гороскопов.
## ПРОБЛЕМА / АЛЬТЕРНАТИВНЫЕ РЕШЕНИЯ

**ПРОБЛЕМА, ПОТРЕБНОСТЬ**
Современные люди, особенно молодые взрослые, испытывают острую потребность в самопознании и поиске смысла жизни. По данным ВЦИОМ 2024, 42% россиян читают гороскопы. Однако существующие решения разрозненны, дороги (консультации астрологов от 2000 руб./сеанс) или требуют глубоких знаний в эзотерике.

Проблема оценивается в:
- Время: пользователи тратят часы на поиск информации по разным источникам
- Деньги: до 10,000 руб./месяц на консультации и курсы
- Усилия: необходимость изучения сложных систем астрологии и нумерологии

**АЛЬТЕРНАТИВЫ**
Сейчас пользователи используют:
- Разрозненные онлайн-ресурсы и сайты с гороскопами
- Консультации астрологов и нумерологов
- Книги и курсы по эзотерике
- Зарубежные приложения без русского языка

**АНАЛИЗ КОНКУРЕНТОВ**
- **Co-Star**: Сильные стороны - красивый дизайн, популярность. Слабые - нет русского языка, только гороскопы, нет матрицы судьбы и Таро
- **The Pattern**: Сильные стороны - качественная астрология. Слабые - нет русского языка, ограниченный функционал, нет Таро
- **"Матрица судьбы. Нумерология и Таро"**: Сильные стороны - русский язык, есть матрица. Слабые - устаревший интерфейс, множество багов, неполная расшифровка

**Наше преимущество**: Кросс-платформенность с единой базой данных между мобильным приложением и веб-версией (https://linadugau-mystik-365c.twc1.net/), что обеспечивает синхронизацию данных пользователя на всех устройствах.

## ТЕХНОЛОГИИ И ИНСТРУМЕНТЫ

**Основа решения**
Кросс-платформенная архитектура на базе React Native для мобильного приложения и React для веб-версии с единой базой данных MySQL.

**Технологический стек**
- **Frontend**: React Native (мобильное приложение), React (веб-версия)
- **Backend**: Node.js + Express.js
- **База данных**: MySQL с поддержкой SSL
- **Инфраструктура**: Timeweb Cloud, Docker-контейнеры
- **Дополнительные технологии**: 
  - Expo для разработки и деплоя мобильного приложения
  - Zustand для управления состоянием
  - React Query для работы с API
  - NativeWind для стилизации

**Почему выбрали именно эти технологии**
- **React Native**: Позволяет разрабатывать для iOS и Android одновременно, экономя время разработки
- **Единая кодовая база**: Максимальное переиспользование кода между мобильной и веб-версией
- **MySQL**: Надежность, масштабируемость, поддержка сложных запросов для астрологических расчетов
- **Node.js**: Высокая производительность для API, большая экосистема библиотек

**Использование ИИ и автоматизации**
Проект разработан с использованием AI-ассистированного программирования (Cursor, ChatGPT) для ускорения процесса разработки в условиях ограниченного времени и ресурсов. Это позволило создать MVP за 3 недели вместо обычных 2-3 месяцев.

**Уникальная технологическая экспертиза**
Команда обладает опытом в:
- Кросс-платформенной разработке мобильных приложений
- Создании сложных математических алгоритмов для астрологических расчетов
- Интеграции с внешними API для получения актуальных данных
- Оптимизации производительности для работы с большими объемами данных
