# MYstik — веб-версия

Отдельная веб-версия приложения MYstik по мотивам мобильного приложения. Работает в браузере как самостоятельный SPA.

## Возможности

- **Главная** — быстрый доступ к карте дня, гороскопу, матрице судьбы и тестам
- **Таро** — гадание на картах (карта дня, три карты, любовный расклад и др.)
- **Эзотерика** — гороскоп по дате рождения и матрица судьбы
- **Тесты** — тесты по методике Клифтона, PAEI, тип привязанности, архетип
- **Профиль** — вход/регистрация, подписка, настройки, поддержка
- **Подписка** — премиум 990₽/мес (локальная активация для демо)

Данные хранятся в `localStorage` (пользователи, подписка, дата рождения, карта дня, результаты тестов).

## Запуск

```bash
cd mystik-web
npm install
npm run dev
```

Откройте в браузере: http://localhost:5173

## Сборка

```bash
npm run build
npm run preview
```

Собранные файлы будут в папке `dist/`.

## Стек

- React 18, TypeScript
- Vite
- React Router 6
- Lucide React (иконки)
- Локальное хранилище (localStorage) вместо SQLite

## Отличия от мобильной версии

- Нет аналитики в БД (логи кликов по разделам не сохраняются)
- Нет экспо/React Native — только веб
- Матрица судьбы в веб-версии упрощена (список точек без SVG-схемы)
- Подписка и авторизация работают локально в браузере
